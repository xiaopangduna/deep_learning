# exports

板端模型转换相关目录：按芯片厂商存放**本项目的转换脚本/配置**，以及本地自备的**原厂 SDK**。

Git 只跟踪说明与脚本等白名单文件，规则见同目录 `.gitignore`。各厂商细节见其下 `README.md`。

## 目录约定

```
exports/
  <厂商>/
    README.md    # 该厂商说明与使用步骤
    sdk/         # 原厂 SDK 复制件（不进 Git）
    ...          # 本项目脚本、模型转换配置等
```

### SDK 放置流程

1. 将官方发布包下载/解压到 `tmp/`（来源清晰、可随时清理）
2. **复制**（不要软链）到 `exports/<厂商>/sdk/`

这样路径稳定，容器挂载后也不会因软链指向宿主机绝对路径而失效。
